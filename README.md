# YourRentsNg

This project was generated with [Angular CLI](https://github.com/angular/angular-cli) version 17.0.10.

## Execute the application in develpment

1. Start the backend API, follow the instructions in the [YourRentsAPI](https://github.com/your-rents/your-rents-api) repository.


2. Start the frontend application:

    ```bash
    ng serve
    ```

    If you just cloned the repository, you need to install the dependencies first:

    ```bash
    npm install
    ```

    The application will be available at `http://localhost:4200/`.
3. Login with the following credentials:
    - Normal user:
        - Username: `user`
        - Password: `user`
    - Admin user:
        - Username: `admin`
        - Password: `admin`

## Development server

Run `ng serve` for a dev server. Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.
